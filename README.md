# Sistema de Ventas POS

Sistema de punto de venta para administrar múltiples negocios.

## Negocios

- BakeQuiri
- SpicyRoll

## Funciones

- Venta de productos
- Carrito de compra
- Métodos de pago
- Control de inventario
- Historial de ventas
- Resumen de ventas
- Clientes
- Soporte para múltiples negocios
- Integración con Supabase

## Base de datos

El sistema utiliza Supabase como base de datos principal.
